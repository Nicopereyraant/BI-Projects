# CSV de ejemplo

Cinco archivos POS ficticios del 16/11/2026, uno por sucursal. Contienen 15 tickets y 30 líneas en total. Se usaron para probar manualmente el flujo de n8n; ese día es parcial y no representa la operación completa de la cafetería.

El [contrato del archivo](../../docs/contrato_csv.md) explica columnas y validaciones. No incluir aquí exports con datos reales ni credenciales.
